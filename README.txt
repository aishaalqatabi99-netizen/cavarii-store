1) ثبّت Node.js من nodejs.org
2) افتح المجلد في VS Code ثم Terminal:
   npm install
   npm start
3) المتجر:  http://localhost:3000
   الإدارة: http://localhost:3000/admin.html   (كلمة السر الافتراضية: change-me)
   لتغيير كلمة السر:  ADMIN_PASS=كلمتك npm start
4) عدّل رقم التحويل واسم الحساب من أعلى السكربت في public/index.html (CFG)
